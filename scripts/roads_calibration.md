## 資料源與 schema

### A. 線型 — data.gov.tw 105020「省道公路路線圖資」

實際下載到的**不是 SHP，是 KMZ**（dataset 的 `resourceFormat` 標「壓縮檔」）。
結構為三層：`roads_105020.zip` → `省道公路路線KMZ_11502.zip` → 每條路線一個 `P####.kmz` → `doc.kml`。
KML 座標已是 **WGS84 經緯度**，因此不需要 TWD97→WGS84 轉換（`pyproj` 改用於把經緯度投影到 EPSG:3826 做平面長度計算）。

每個 `Placemark` = 一個工務段，屬性寫在 `description` 的 HTML 表格裡。欄位（名稱、型別、實際值）：

| 欄位 | 型別 | 台18 首筆實際值 |
|---|---|---|
| 公路編號 | 字串 | `台18` |
| 公路編碼 | 字串 | `P0180` |
| 工程處 | 字串 | `雲嘉南區養護工程分局` |
| 工務段 | 字串 | `水上工務段` |
| 縣市別 | 字串 | `嘉義縣` |
| 代養機關 | 字串 | （空） |
| 方向 | 字串 | `順向` |
| 調查日期 | 日期字串 | `2014/9/5` |
| **樁號範圍** | 字串 `nK+nnn至nK+nnn` | `0K+000至8K+531` |
| 幾何 | MultiGeometry/LineString | WGS84 lon,lat,0 |

**路線編號欄位的實際值是 `台18` / `台21`**（不是 `18`、`0018` 或 `TW18`）；
KMZ 檔名用的公路編碼是 `P0180` / `P0210`（`P0211` 為台21甲，已排除）。

**schema 含里程屬性：是。** 每段有官方「樁號範圍」，所以里程指派走「每段線性內插」，
不需要用里程牌做整體線性校正（見下方 §校正診斷）。

### 校正診斷（線性擬合，**未套用**）

對每支里程牌求其在折線上的最近點累積里程 `s`，與官方樁號 `m` 最小平方擬合 `m = a·s + b`：

- **a = 1.000170**、**b = -19.80 m**

a 已極接近 1、b 極接近 0，代表 KML 的官方「樁號範圍」逐段內插後，里程尺度與里程牌本身一致。**因此不套用這組 a/b**——套上去只會是對殘差的過度擬合，也違反「不得調參到剛好過」。
